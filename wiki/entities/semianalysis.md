# SemiAnalysis

Independent semiconductor and AI infrastructure research firm. Publishes a
paid newsletter (Substack) + institutional data products. Founded/led by
**Dylan Patel**.

## Facts

- Publications used as primary data source for GPU/datacenter market.
- Maintains institutional data products: **AI Cloud TCO model**, **InferenceX / InferenceMAX**, **ClusterMAX**, **Tokenomics Dashboard**, **Memory Model**, **GPU Rental Price Dashboard**.
- Launched **H100 1-year contract price index** publicly on 2026-04-02 (previously institutional-only since 2023). [^semi-2026-04]
- Index methodology: monthly survey of 100+ Neocloud providers + compute buyers/sellers, 25th–75th percentile range, validated with transaction data. [^semi-2026-04]
- Tracks contract prices across 3m–5y tenors for H100, H200, B200, B300, GB200, GB300, MI300, MI325, MI355. [^semi-2026-04]
- Self-reported: consumed billions of tokens in 7 days at ~$5/M tok avg; uses agentic tools for dashboarding, scraping, data wrangling, financial modeling. [^semi-2026-04]
- Publishes "Claude Commits Daily" tracker. [^semi-2026-04]

## Claims / views

- Thesis: GPU rental pricing is in a **self-reinforcing upcycle** through 2026. [^semi-2026-04]
- Bullish on Neoclouds (CoreWeave, Nebius, IREN); believes public-market sentiment mispriced given tightening supply. [^semi-2026-04]
- Predicts **Claude Code will be 20%+ of all daily commits globally by end of 2026**. [^semi-2026-04]
